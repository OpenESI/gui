# OpenESI 10 "Phoenix"

**Open Embedded System Interface** - Versione 10.0

## Caratteristiche Principali

- 🚀 **Architettura Moderna**: Sistema GUI completamente rivisto
- ⚡ **Prestazioni Ottimizzate**: Cache intelligente e rendering avanzato
- 🎨 **Skin System Avanzato**: Parser skin con supporto moderne feature
- 🔧 **Compatibilità Completa**: Mantiene compatibilità con plugin esistenti

## Novità in OpenESI 10

### Sistema Screen Rivisto
- Gestione eventi avanzata (onShow/onHide/onClose)
- Focus management migliorato
- Timer system per automazione

### Componenti GUI Ottimizzati
- Cache intelligente per performance
- Gestione connessioni robusta
- Nuovo BlinkingComponent per effetti

### Sistema Skin Potenziato
- Parser skin con cache integrata
- Gestione colori e fonts avanzata
- Scaling automatico per risoluzioni

### Rendering Accelerato
- Lazy rendering per efficienza
- Supporto hardware acceleration
- Cached rendering per contenuti statici

## Requisiti di Sistema

- Enigma2 core
- Python 3.6+
- Hardware con supporto OpenGL ES 2.0 (consigliato)
